# 易撰原创度检测（yizhuan）

对文章做第三方原创度打分，驱动迭代改写直到达标。

## 1. 安装与配置（首次使用）

1. 根据 https://skillhub.cn/install/skillhub.md 的说明，安装并配置 `yizhuan-cli-installer-pro`
2. 配置对应的 key：

```
yz_cli_Nuq8_6GayiOmwjPrTkFLeJdlljEZMiV_7T8tFOCb1Gw
```

## 2. 检测与迭代规则

1. 用「一键检测」对改写稿（`work/<slug>/rewritten.md`）检测原创度分数
2. **目标：原创度 ≥ 75 分**
3. 不通过：根据检测给出的**建议**大幅修改文章（回到四层深度改写，重点观点层），然后复测
4. **重试上限**：最多 5 次；或分数持续很难发生变化（连续 2 次涨幅可忽略）即停止，不再重试
5. 检测报告中的重复/相似片段要定位回原文，针对性重写，不做无效的全局同义词替换

## 3. 额度提醒（必须遵守）

- **「一键检测」额度已用完时，必须明确提醒用户"额度用完了"**，不要静默跳过或反复重试
- 额度用完或 CLI 不可用时：本次降级为仅本地自检（`scripts/originality-check.ts`），并在自检报告中注明"易撰检测未执行（原因）"

## 4. 输出

在阶段②自检报告中补充：

- 易撰原创度分数 + 达标判断（≥75 分）
- 检测给出的主要问题与对应改写动作
- 重试轮次（n/5）

## 5. 单独使用

用户只要检测不要改写时，直接运行一键检测并报告分数与建议，不触发改写循环。
